# Alcance actualizado: exclusivamente CNN

El frontend trabaja únicamente con redes convolucionales 2D.
Dataset: carpeta principal con una subcarpeta por clase.
Formatos: PNG, JPG y WebP. No se requiere ZIP.
Las imágenes se decodifican y validan en el navegador.
Los CSV tabulares del ejemplo anterior ya no son el dataset de este flujo.
Dos gráficos: precisión y pérdida; ambos con entrenamiento y validación.
El entrenamiento continúa simulado y no ejecuta TensorFlow.
No existe base de datos ni persistencia al recargar.
Los manuales anteriores requieren actualización a este nuevo alcance.
